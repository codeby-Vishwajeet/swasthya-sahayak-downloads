# Swasthya Sahayak

Your Health Awareness Companion.

Swasthya Sahayak is an Android application
designed to support health awareness and
preliminary screening education.

## Features
- Hindi and English language support
- Guided health questionnaires
- Educational screening summaries
- Preventive health information
- Doctor report-sharing option
